# Gut Flora Atlas — native React port (in progress)

See `../PORTING_PLAN.md` for the full component inventory, status, and
porting order. Short version: this is an in-progress, systematic port of
`gut-flora-atlas.html` (a hand-patched minified bundle) to a normal React +
Vite + Tailwind v4 project. It does not replace the original app yet.

## Development

```bash
npm install
npm run dev      # http://localhost:5173/
npm run build    # -> dist/
```
